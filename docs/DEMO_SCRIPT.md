# Kontext demo script (60–90 seconds)

Use this shot list for a screen recording on a physical iPhone with Apple Intelligence enabled when possible. The on-screen product name may still read **Capture** until the iOS display name is renamed; narrate as **Kontext**.

| Time | Shot | Narration / action |
|------|------|------------------|
| 0:00–0:08 | Home screen, tap capture | “This is Kontext—throw in a poster, link, or note without filing it first.” |
| 0:08–0:22 | Share sheet → event poster screenshot → optional **Remind me** | Share from Photos, toggle Remind me if it’s a URL, save. |
| 0:22–0:38 | Open capture detail → **Suggested actions** card | “Kontext proposes an event from the poster—dates come from on-device extraction, not the cloud.” |
| 0:38–0:52 | Tap **Approve** → Calendar edit → Save | “I approve once; write-only Calendar access. Nothing hits my calendar until I confirm.” |
| 0:52–1:05 | Search tab, natural language query | “Later I find it with semantic search—‘dinner marina Friday’—without remembering the folder.” |
| 1:05–1:15 | Settings → privacy / action extraction + site eval table (optional B-roll) | “Everything stayed on the phone. Eval numbers on the site show how well extraction performs on real hardware.” |
| 1:15–1:20 | End card: Kontext logo / TestFlight | “Kontext: capture, it proposes, you approve.” |

**Tips:** Keep the phone in Do Not Disturb, use a clean demo calendar, and pre-seed one context so search feels instant. Rehearse permission prompts so the Calendar sheet doesn’t stall the take.
